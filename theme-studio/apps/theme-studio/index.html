Parts

A theme part is a named region of Lucidos, such as chat text or the header titles. A theme can give it a colour, a glow or wider letter-spacing, each under a cap. Lucidos owns every selector, so a part cannot move, hide or cover anything.

The same scope as the tokens. Both modes writes parts, Dark writes dark.parts and Light writes light.parts. A Dark or Light value wins over Both modes. Set none on a shadow or filter to switch a shared effect off in one mode.

With Effects set to Reduce (Settings, Appearance, Theme), part shadows and filters do not show on that device. This device reduces effects now, so the live preview shows none.

Theme parts need a newer Lucidos.
