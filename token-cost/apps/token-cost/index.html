Currency

Providers bill in USD, so the rates above are entered in one base currency and everything else is converted for display only. Changing the base does not touch the numbers you typed: it only changes what unit they are read as. The dashboard's own currency picker is per device, kept in this browser, so a shared workspace can be read in kroner on one machine and dollars on another.

Rates are stored in artifacts/token-cost/pricing.json next to the model prices, so the dashboard converts offline and a currency you never refresh keeps working at the last rate it saw. Update rates pulls the daily ECB reference rates from frankfurter.dev, which needs no key. Add any three-letter code and it appears in the dashboard picker.

Long-context premium

A premium some providers charge once a single prompt crosses the threshold, applied only to models whose id ends in [1m]. Anthropic removed this surcharge for Opus 4.6 and later, so both multipliers ship at 1.0 and every call here is priced at the flat rate. Raise them only for a model that still bills a long-context tier. OpenAI's own tier starts at 272k, above this bucket's edge, and is not modelled.

Ring sound

What plays when a live call lands, while the speaker in the header is on. Click a card to pick it and hear it. Every built-in is public domain or synthesized here, and provenance is recorded in apps/token-cost/sounds/README.md. The choice is per device, kept in this browser, so a phone and a laptop can ring differently.

A custom clip is uploaded to artifacts/imported/ and played from there. Keep it under a second or two: it fires on every call, and anything longer overlaps the next one.

Edits save themselves a moment after you stop typing, so there is nothing to press. Stored as JSON at artifacts/token-cost/pricing.json, so it is version-controlled with the rest of the workspace and you can still edit it by hand.
