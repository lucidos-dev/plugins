Cache and keep-alive

Uses the range, type filter and Group by chips above. Rows always include the day and model. Cache evidence updates with the hourly rollup.

Keep-alive cost vs savings

Ping spend includes cache reads, writes, fresh input and output. Avoided rewrite spend requires an ended run with an engine-confirmed saving, a known TTL and a matching context. Unknown runs have no estimated saving. Pings are dated when billed; savings are dated when the wait ends.

Cache write vs read spend

Daily spend on cache writes, cache reads and uncached input, including the reported lifetime price. Output is excluded here.

Cache rewrites by cause

Counts calls that wrote cache. A cold write after a recorded handoff, model switch or evidenced TTL expiry gets that cause only when it is unambiguous. First writes, partial writes and missing or conflicting evidence count as unknown.

Handoffs

Per handoff checkpoint: what writing the handoff narrative cost (a warm handoff; a cold one starts from the engine's brief, so it costs nothing), and the cost per call over the last 20 calls before the handoff and the first 20 after it. Verdicts are the handoff estimate's: a "pays" verdict held when calls got cheaper.

Currency

The price table is in one base currency, USD, as providers bill. Every other currency is converted for display only, and nothing stored is ever converted. The dashboard's own currency picker is per device, kept in this browser, so a shared workspace can be read in kroner on one machine and dollars on another.

 
CurrencyPer 1 USD

Rates are stored in artifacts/token-cost/settings.json, so the dashboard converts offline and a currency you never refresh keeps working at the last rate it saw. Update rates pulls the daily ECB reference rates from frankfurter.dev, which needs no key. Add any three-letter code and it appears in the dashboard picker.

Producer labels

How each producer the engine reports is named in the table and the filter. An unlabelled auxiliary purpose reads as its name; any other unlabelled producer shows its raw id.

Edits save themselves a moment after you stop typing, so there is nothing to press. A price you change is written to config/model-prices.json, the workspace override of Lucidos's price table, and never to the cards Lucidos ships. Producer labels and exchange rates go to artifacts/token-cost/settings.json. Both are JSON, version-controlled with the rest of the workspace, and you can still edit them by hand.
