Currency

The price table is in one base currency, USD, as providers bill. Every other currency is converted for display only, and nothing stored is ever converted. The dashboard's own currency picker is per device, kept in this browser, so a shared workspace can be read in kroner on one machine and dollars on another.

 
CurrencyPer 1 USD

Rates are stored in artifacts/token-cost/settings.json, so the dashboard converts offline and a currency you never refresh keeps working at the last rate it saw. Update rates pulls the daily ECB reference rates from frankfurter.dev, which needs no key. Add any three-letter code and it appears in the dashboard picker.

Producer labels

How each producer the engine reports is named in the table and the filter. An unlabelled auxiliary purpose reads as its name; any other unlabelled producer shows its raw id.

Ring sound

What plays when a live call lands, while the speaker in the header is on. Click a card to pick it and hear it. Every built-in is public domain or synthesized here, and provenance is recorded in apps/token-cost/sounds/README.md. The choice is per device, kept in this browser, so a phone and a laptop can ring differently.

A custom clip is uploaded to artifacts/imported/ and played from there. Keep it under a second or two: it fires on every call, and anything longer overlaps the next one.

Edits save themselves a moment after you stop typing, so there is nothing to press. A price you change is written to config/model-prices.json, the workspace override of Lucidos's price table, and never to the cards Lucidos ships. Producer labels and exchange rates go to artifacts/token-cost/settings.json. Both are JSON, version-controlled with the rest of the workspace, and you can still edit them by hand.
