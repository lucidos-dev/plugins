Processing applied to the original 2.23s 44.1kHz mono Ogg Vorbis:
- trimmed to 0.22s - 1.80s (leading silence and the dead tail removed), 1.58s long
- 4ms fade in, 60ms fade out, so neither edge clicks
- peak normalised to 0.89 (the source clips at 1.02)
- downsampled to 22.05kHz, encoded AAC 48kbps mono -> 12.4 KB
